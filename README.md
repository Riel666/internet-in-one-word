One word for the whole internet: **enshittification** — the slow, funny, and
all-too-true decay of every platform you once loved into ads, spam, and slop.
It is funny by itself, it is true about the internet as a whole rather than
one app, and it is not the first obvious word anyone reaches for.

## Run it

```sh
python3 main.py
```

Writes the single word to `/output/entry.txt`.
